# Hazimeh Home Line – Turkomaz® Frontend Website

🚀 A modern, responsive front-end website built for **Hazimeh Home Line – Turkomaz®**, a family-owned premium housewares business with over **35+ years of experience** in the Lebanese market.

This project was designed and developed to create a strong digital presence that reflects the brand’s quality, scale, and professionalism.

---

## 🌐 Live Preview
👉 https://hazimehomeline.com  
*(Currently displaying an “Under Construction” page – full launch coming soon)*

---

## ✨ Features
- Fully responsive design (desktop, tablet, mobile)
- Modern UI with smooth animations
- Custom preloader with brand identity
- Interactive product sections & categories
- Mobile-friendly navigation
- WhatsApp floating contact button
- Contact form UI
- Google Maps integration
- Clean, business-oriented layout

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript**
- Google Fonts (Playfair Display, Montserrat)

No frameworks were used — everything is built from scratch to ensure performance and full control over the UI.

---

## 📌 Project Purpose
This project was created to:
- Serve as the official front-end website for Hazimeh Home Line
- Showcase front-end development skills in a real business context
- Combine technical execution with real-world business needs
- Act as a foundation for a future **full-stack e-commerce platform**
